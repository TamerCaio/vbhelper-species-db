# VBHelper Species Database

Banco de dados público de espécies de Digimon para uso pelo VBHelper.
Mapeia `cardId` (dimId do card DIM/BEM oficial) + `charaIndex` (slot no card) para nome, nível,
tipo e golpes especiais da espécie.

Uso
---

O arquivo `species.json` é consumido via:

https://raw.githubusercontent.com/TamerCaio/vbhelper-species-db/main/species.json

Contribuindo
---

Veja CONTRIBUTING.md. Todo PR precisa passar na validação de schema (rodada automaticamente via GitHub Actions).
